PLAYMARKET — демонстрационный шаблон игрового маркетплейса

Файлы:
- index.html — структура сайта
- style.css — оформление и адаптация под телефон
- script.js — каталог, поиск, фильтр, избранное и демо-модальные окна

Как открыть:
1. Распакуй ZIP в отдельную папку.
2. Открой index.html в браузере.

Как опубликовать на GitHub Pages:
1. Создай новый публичный репозиторий на GitHub.
2. Загрузи index.html, style.css, script.js и README.txt в корень репозитория.
3. Открой Settings -> Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку main и папку /(root), нажми Save.

Важно:
Это фронтенд-прототип. Регистрация, аккаунты, платежи, реальные заказы,
серверная база данных и админ-панель не подключены. Демо-вход не является
защищённой авторизацией. Цены и товары — примеры, их можно изменить в script.js.
Для настоящего магазина потребуются сервер, база данных, безопасная авторизация,
проверка продавцов и подходящая платёжная инфраструктура.
